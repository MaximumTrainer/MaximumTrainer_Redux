
### 🐛 How to Report a Bug or Issue

If you encounter a problem while running MaximumTrainer Redux, please let us know! Reporting defects helps us improve the software for everyone.

To submit a bug report, please follow these steps:

1. **Check for duplicates:** Briefly scan the [Issues page](https://github.com/MaximumTrainer/MaximumTrainer_Redux/issues) to make sure the problem hasn't already been reported by someone else.
2. **Open a new issue:** Navigate to our [Issue Tracker](https://github.com/MaximumTrainer/MaximumTrainer_Redux/issues) and click the **New issue** button.
3. **Provide the details:** To help us investigate and fix the problem as quickly as possible, please include the following in your report:
* **Explanation:** A clear description of what went wrong, what you expected to happen, and the exact steps to reproduce the problem.
* **Screenshots (Highly Recommended):** If the issue is visible on your screen, please take a screenshot and drag-and-drop it into the issue description.
* **Application Logs:** Please extract and attach the relevant application logs from when the error occurred. You can paste short log snippets into a code block or attach the log file directly to the issue.
